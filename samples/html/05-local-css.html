Local CSS — one stylesheet

This page links a local stylesheet: 

<link rel="stylesheet" href="./css/theme.css">

The HTML viewer's Rust side (resolve_html_assets in src-tauri/src/core/html_assets.rs) reads css/theme.css from disk and replaces the <link> with an inline <style> block before the iframe ever sees the markup. That's why this works inside the allow-same-origin sandbox without violating the host CSP — the iframe never issues a stylesheet network request.

Visible signals that theme.css loaded

  • Headings are blue (--accent).
  • This paragraph sits on the cream page background (--bg).
  • Inline code has a grey pill background.
  • Status colour helpers: good · warn · bad · muted.

What to spot-check

  1. If the page renders unstyled (black headings, white background), the inliner failed.
  2. If you see a CSP violation in DevTools for ./css/theme.css, the <link> wasn't inlined and the iframe attempted a network fetch.
  3. Editing css/theme.css on disk and reloading the file should visibly change the colours (the watcher re-renders).
