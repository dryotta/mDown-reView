Local CSS — three stylesheets, cascading

This page links three local stylesheets in order: 

<link rel="stylesheet" href="./css/reset.css">
<link rel="stylesheet" href="./css/theme.css">
<link rel="stylesheet" href="./css/layout.css">

Each <link> is independently inlined by resolve_html_assets in the order it appears, so the cascade is preserved — reset.css first (box-sizing + base type), then theme.css (palette via custom properties), then layout.css (grid + cards consuming those properties).

The <link> tags are inlined in declaration order so layout.css wins ties.

Two-column section

What works

  • Custom properties (--accent) defined in theme.css are read by layout.css.
  • Media query in layout.css collapses to a single column under 600px viewport width.
  • Multiple stylesheets do not double-inline; each is replaced once.

What to spot-check

  • Resize the window — the grid should flow.
  • Inspect the iframe DOM: there should be three <style> blocks instead of three <link> tags.
  • No CSP violation entries in DevTools.
